## Borrowed DNA

| From the site | Into the system |
|---|---|
| Hard colored offset shadows (no blur) | `--shadow-wafer-y/r/g/b` + `.w-slab` |
| Cream paper surfaces `#FDFCF0` | `--wafer-cream` / `--wafer-paper` |
| Charcoal stage background `#2D3E50` | `--wafer-stage` + `.w-stage` |
| Large squircle radius | `--radius-m/l` bumped to 20/28 |
| ALL CAPS rails with index numbers | `.w-rail` |
| Pill link rows | `.w-pill-link` |
| Soft floating blobs | `.w-blob` |
| Yellow as favourite accent | `--wafer-yellow: #fac84d` |

## Keep / remix (not copy)

- Keep vivid Y/R/G/B pop (site is more bakery-muted; our system stays fresher)
- Keep future-kid geometry + quiet float
- Keep Nunito soft rounded type as default; Fraunces only for quote moments
- Do **not** copy logo text, personal copy, or exact page structure as a clone

## Signature formula

**expensive** = cream paper · charcoal stage · generous padding · caps labels · serif quotes  
**playful** = hard color shadows · big radius · candy accents · soft blobs · wafer layers
